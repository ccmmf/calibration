# Joint calibration

One inversion over the cal/val treatments the curated record supports, rather
than a per site pass. The fitted target is the salinas SOC period mean level
plus its treatment contrasts; the modesto N2O treatment contrast is held out of
the likelihood and scored as validation. Physiological parameters are held at
strong priors; the compost events carry an amendment quality scaling documented
beside the prepared inputs in the workspace.

This directory holds configuration only, the same shape as
`examples/1_salinas_soc`. The code is the generic numbered scripts in
`../../scripts`, and the run artifacts live in the workspace.

## Workspace

The **workspace** is the directory the run artifacts live in (in this case it is 
shared CCMMF directory), outside the repo. It holds the prepared model inputs, the
expanded settings, the run tree and the result cache. Nothing in it is committed; 
the repo carries configuration only.

Set `CALIBRATION_DATA_ROOT` to the directory that holds it. Every path in
`config.yml` is built from that root, so no absolute path is committed:

```sh
export CALIBRATION_DATA_ROOT=/path/to/artifacts
```

The layout under that root:

```
cal_val_joint/
  inputs/    events prepared from the curated management record
  run/       settings.xml, sipnet.default.param, scripts/, per iteration output
  cache/     obs.rds, target.rds, prior.rds, result.rds
```

`inputs/` and `cache/` together are what is needed to re-run the scoring and
plotting steps or to audit the result, and they are small enough to distribute.
`run/` is per iteration model output, is regenerated by
`scripts/030_calibrate.R`, and is not worth carrying.

| file | what it is |
|---|---|
| `config.yml` | targets, priors, pinned parameters, PFTs, EKI settings, workspace paths |
| `template.xml` | whole-run PEcAn settings; expanded per block by `015_build_settings.R` |
| `blocks.csv` | one row per fitted treatment: dates, PFTs, and the exact met, template IC, and events file each block runs |

## Running it

```sh
export CALIBRATION_DATA_ROOT=/path/to/artifacts
CFG=examples/2_joint_soc_n2o/config.yml
Rscript scripts/010_prepare_observations.R -c $CFG   # raw observation cache
Rscript scripts/012_build_target.R         -c $CFG   # contract to the fitted target
Rscript scripts/015_build_settings.R       -c $CFG   # settings + default.param + template ICs
Rscript scripts/020_build_priors.R         -c $CFG
Rscript scripts/030_calibrate.R            -c $CFG   # add --dry-run --particles 3 for a proof pass
Rscript scripts/040_plot.R                 -c $CFG
```

Run these from the workspace rather than the repo: the settings carry the array
launcher as `./scripts/sge_array_launcher.sh` and `qsub` runs with `-cwd`, so
the working directory has to be the workspace, where `scripts/` sits beside
`settings.xml`.
